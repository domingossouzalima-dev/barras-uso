# barras-uso

Plugin para o [Claude Code](https://claude.com/claude-code) que mostra, junto ao prompt, barras de preenchimento com percentual para:

- **Ctx**: janela de contexto
- **5h**: limite da janela de 5 horas
- **Sem**: limite semanal

## Instalação

```
/plugin marketplace add domingossouzalima-dev/barras-uso
/plugin install barras-uso@barras-uso
```
